# Assistsx
- 用于[assistsx-js](https://github.com/ven-coder/assistsx-js)开发的自动化插件运行平台App，支持插件的本地安装、局域网安装、在线加载方式运行
- 该App基于[assists-web](https://github.com/ven-coder/Assists)开源库开发
- **开源版说明**：本仓库不包含插件商店与节点分析服务相关源码
